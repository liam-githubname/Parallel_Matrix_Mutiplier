# Multi-threaded Matrix Multiplier
This project is small and not flashy but I thought it was cool. All my professor asked me to do was parallelize a matrix multiplication algorithm. I decided to do it in Rust because I wanted to learn the language at the time. It was exciting because parallelized matrix operations are what GPUs do. I also took a Matrix and Linear Algebra class so this was the first time I implemented high level math that I learned.
